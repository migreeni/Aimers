# Aimers

## Dataset

- **Training Data Path**  
  All training data files are located in:  
  `dataset/train/train`

- **Test Data Path**  
  All test data folders follow the format:  
  `dataset/test/TEST_**`

## Output

- **Result Directory**  
  All result files should be saved in the following folder:  
  `result/`

- **Submission Format**  
  The format of each result file must match exactly with:  
  `result/sample_submission.csv`
